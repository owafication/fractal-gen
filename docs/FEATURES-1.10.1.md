# Mandelbrot Live Wallpaper 1.10.1

## Quick Controller

The resizable Quick Controller now includes:

- Play/Stop live desktop output
- Pause/Start Zoom
- Pause/Start Colours
- Save Preset As
- Save Image
- Copy Coordinates
- Load Preset
- Open Editor
- Exit App

Zoom and colour labels reflect their independent active state.

## Persistent preview controls

The preview overlay preserves its existing desktop, animation, coordinate-jump, and Quick Controller actions and adds the requested direct commands:

- Set Live
- Save Preset As
- Copy Coordinates
- Save Image

Copied coordinates use the same `centreX,centreY,scale` string accepted by the coordinate editor and journey tools.
