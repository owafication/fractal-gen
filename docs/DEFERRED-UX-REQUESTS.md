# User-requested UX and output settings

**Status: Implemented in 1.13.0.**

The requests recorded during the 1.12.6 Windows build-fix scope are now implemented:

- User-defined output folder for static renders, saved images and slideshow captures
- PNG, JPEG, TIFF and BMP output plus compression/quality control
- Explicit desktop-mode selector with Apply and Set as default
- None, Static image, Live image, Slide show and Journey modes
- Preview Animation selector removed
- Dedicated Journey Settings access
- Scrollable Equation Editor dropdowns
- Independent Settings, Equation and Palette tool windows
- Live Palette Editor preview, including saved-palette loading

See `docs/FEATURES-1.13.0.md` and `docs/VERIFICATION-1.13.0.md`.
