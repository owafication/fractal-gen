# Mandelbrot Live Wallpaper 1.11.6

## Quick Controller expanded

The Quick Controller now mirrors the remaining hover-menu actions so they are available from the floating controller window without reopening the preview overlay.

Added to the Quick Controller:

- Apply Settings Live
- Static Desktop
- Slideshow Desktop
- Stop Desktop
- Jump to Coordinates...
- Start/Stop Preview Zoom
- Start/Stop Preview Colours
- Start/Stop Desktop Zoom
- Start/Stop Desktop Colours
- Render Hi-Res...

Already-existing actions remain available without duplication:

- Play / Stop live wallpaper
- Save Image
- Copy Coordinates
- Load Preset...
- Open Editor
- Exit App

The quick window updates its preview and desktop animation button labels to match the current runtime state.
